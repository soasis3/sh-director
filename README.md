# SH Director

Story, assets, shotboard and reference-driven generation studio.

Web: https://soasis3.github.io/sh-director/

The web edition saves projects and uploads on the current device using IndexedDB. It does not yet synchronize projects between devices or execute remote GPU jobs. Public Krea moodboards can be searched and attached as visual references and style directions; no Krea generation API key is required.

This repository contains only the web UI and a public catalog snapshot, not production project files, original media, local model configuration or credentials.
